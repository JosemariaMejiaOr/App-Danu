# Fleet Management Application

This application helps fleet managers track and control expenses for their fleet of trucks.

## Features

- User management (registration and login for fleet managers)
- Truck management (add, view, edit, delete trucks)
- Expense management (register expenses with image uploads, view expense history)
- Dashboard for data visualization (investment per truck, spending by zone)

## Tech Stack

- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Image Storage:** Local file storage (initially)
